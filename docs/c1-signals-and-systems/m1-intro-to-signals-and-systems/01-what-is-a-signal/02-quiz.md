# Chapter 1 - What is a signal?
## Quiz

### Question 1
Which of the following **best describes** a signal?

<div class="mcq" data-answer="b" data-question-id="q-2e946cd9b6b25dea" data-legacy-index="0">
  <ul>
    <li data-option="a">Any physical phenomenon that can be seen or heard </li>
    <li data-option="b">A quantity that varies as a function of some independent variable</li>
    <li data-option="c">Any type of data that can be stored in a computer</li>
    <li data-option="d">A periodic waveform described by sines and cosines</li>
  </ul>

### Question 2
A digital audio file (e.g., a .mp3, .wav) is **best modelled** as:

<div class="mcq" data-answer="c" data-question-id="q-d30813d54f1e5fb5" data-legacy-index="1">
  <ul>
    <li data-option="a">A continuous-time signal, because sound is continuous </li>
    <li data-option="b">A continuous-time signal with quantized amplitude</li>
    <li data-option="c">A discrete-time signal with quantized amplitude</li>
    <li data-option="d">A stochastic signal, because all recordings contain noise</li>
  </ul>
  <p class="mcq-feedback"></p>
</div>
